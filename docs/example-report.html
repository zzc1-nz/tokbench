methodology

  • Cost is derived only from token counts and the price book (pricing.py); adapters never compute money.
  • Billable tokens = uncached input + output. Cache reads are billed at the cache-read rate, so cache efficiency is part of the ranking.
  • The Pareto frontier marks points that no other pair beats on both cost and quality. The knee is the frontier point furthest from the cheapest-to-best chord — the pragmatic pick.
  • Retry overhead is every token spent after the first attempt of a cell, i.e. spend that a successful first attempt would have avoided.
  • Cache sensitivity holds observed input/output volume fixed and sweeps the hit rate; the resulting cost curve is linear by construction.
  • Quality grading is heuristic and comparable only within a run.
